Stack

Next.js 16 + TypeScript + Tailwind on Vercel Hobby. Supabase Postgres, Storage and pg-boss queue. Worker with Playwright and tesseract on an Oracle Always Free ARM VM. MV3 extension on Edge Add-ons. Shared deterministic core package.

Hard constraints

$0 budget, no exceptions. Multi-tenant orgs. No API keys outside the worker. No sensitive form values ever read. No fabricated intelligence. Identifiers like TG-ART-2026-000001 and TG-INC-2026-000001.
